主流框架横向对比

LangChain / LlamaIndex / CrewAI / AutoGen / Semantic Kernel / 自研

选择 Agent 框架时，没有「银弹」，只有「最适合你当前阶段的工具」。以下从六个维度对比主流框架：

框架语言核心定位学习曲线社区活跃度优点缺点适用场景
LangChainPython / TS通用 LLM 应用框架中高生态全、工具多、文档完善抽象层重、debug 难快速原型、工具链复杂
LlamaIndexPythonRAG / 数据索引中高数据连接器丰富、检索调优灵活Agent 能力弱于 LangChain知识库问答、文档 Agent
CrewAIPython多 Agent 协作低中高角色定义简单、开箱即用灵活性有限、深度定制难多 Agent 编排、快速验证
AutoGenPython多 Agent 对话中中微软背书、对话流自然版本迭代快、API 不稳定研究原型、对话式 Agent
Semantic KernelC# / Python企业级 AI 编排中高中微软生态、企业集成强非主流语言、社区小.NET 团队、企业 Azure
自研任意完全可控高—无依赖、极致性能开发成本高、维护负担重有特殊需求、团队能力强

选型建议

  • MVP 阶段：CrewAI / LangChain，快出原型。
  • RAG 为主：LlamaIndex。
  • 企业 .NET 栈：Semantic Kernel。
  • 生产级定制：基于 LangChain 或自研薄封装，不要被框架绑死。
