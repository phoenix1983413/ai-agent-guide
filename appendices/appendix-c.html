术语表

45 条核心术语 · 按主题五组分类

术语按五组分类：基础概念 / 架构模块 / 推理与规划 / 安全与治理 / 协议与生态。跨章复用的概念以书中正文章节为准。

一、基础概念

中文英文释义
智能体Agent能感知环境、自主决策、执行行动、反思结果的 AI 系统，本质是「感知 → 决策 → 行动 → 反思」闭环。
大语言模型LLM基于 Transformer 的大规模预训练语言模型，如 GPT-4o、Claude 3、Qwen2.5。
聊天机器人Chatbot只有对话没有行动闭环的 AI，是 Agent 的子集形态。
副驾驶Copilot人在环中、AI 辅助建议的协作形态，自主性低于 Agent。
嵌入Embedding把文本 / 图片转为高维向量，用于相似度搜索和记忆存储。
分词TokenLLM 处理文本的基本单位，中文通常 1–2 字一个 token，计费与截断都以它为单位。
上下文窗口Context Window模型单次能「看到」的最大 token 数，Agent 的记忆管理围绕它展开。
幻觉HallucinationLLM 生成看似合理但事实错误的内容，RAG 与来源标注是主要缓解手段。

二、架构模块

中文英文释义
工作记忆Working Memory当前会话的上下文，随对话滚动更新，超出窗口就压缩 / 摘要。
情景记忆Episodic Memory历史交互事件（某次排查、某次对话），按会话存储可检索。
语义记忆Semantic Memory事实性知识（用户偏好、业务定义），通常存向量库。
程序记忆Procedural Memory「怎么做」的技能固化，如 SOP 流程、验证过的 prompt 模板。
工具使用Tool UseAgent 调用外部函数、API、数据库完成任务的能力。
函数调用Function CallingLLM 原生支持的结构化工具调用，模型输出 JSON 格式 tool_call。
注册表Tool Registry集中管理可用工具的表：名称、Schema、权限策略（见第 11 章网关）。
向量数据库Vector DB存储与检索 Embedding 的数据库，如 Pinecone、Weaviate、pgvector。
知识库Knowledge BaseRAG 检索的文档集合，按租户 / 主题分片管理。
沙箱Sandbox隔离执行不可信代码的环境，如 Docker、Firecracker、E2B。

三、推理与规划

中文英文释义
思维链CoTChain-of-Thought，让模型逐步推理而非一步给答案的 prompting 技术。
思维树ToTTree-of-Thoughts，推理组织成树，支持多候选、回溯、剪枝。
图计划GoPGraph of Plans，用有向图表示计划，支持子计划复用与循环。
ReActReActReasoning + Acting 交替循环：思考 → 行动 → 观察 → 再思考。
重规划Replanning执行失败或环境变化时重新生成 / 修补计划的机制。
推理预算Reasoning Budget控制思考长度的工程手段（时间 / token / 步数 / 成本上限）。
任务分解Task Decomposition把大目标拆成可执行步骤，人工骨架 + LLM 填充是生产主流。
提示词工程Prompt Engineering设计与优化输入提示词以稳定提升输出质量的技术。
检索增强生成RAGRetrieval-Augmented Generation，先检索外部知识再生成，抑制幻觉。
多智能体Multi-Agent多个 Agent 分工协作完成复杂任务的系统，模式含管道 / 辩论 / 层次。

四、安全与治理

中文英文释义
提示词注入Prompt Injection攻击者通过用户输入 / 工具返回篡改指令，让 AI 忽略安全规则。
间接注入Indirect Injection恶意指令藏在被检索的网页 / 文档里，Agent 读到即中招。
权限最小化Least Privilege每个工具只授予完成任务所需的最小权限，危险操作人工确认。
个人身份信息PIIPersonally Identifiable Information，身份证号、手机号等，需入口脱敏。
红队测试Red Teaming模拟攻击者测试系统安全边界，上线前的高危项卡点。
可观测性Observability通过 Tracing / Logging / Metrics 理解 Agent 内部行为的能力。
追踪Tracing记录一次任务的完整调用链（LLM、工具、数据库），可回放复现。
评测集Eval Set带期望结果或评分标准的测试用例集，Agent 迭代的度量衡。
灰度发布Canary / Rollout按用户哈希分桶小流量放量，异常时一键回滚。
人机协同Human-in-the-Loop关键节点保留人工审核 / 接管的设计原则。

五、协议与生态

中文英文释义
模型上下文协议MCPModel Context Protocol，Anthropic 提出的模型 ↔ 工具 ↔ 数据统一连接协议。
Agent 间协议A2AAgent-to-Agent，Google 提出的 Agent 发现与通信协议。
智能体名片Agent CardA2A 中 Agent 发布自身能力与端点的 JSON 描述。
JSON-RPCJSON-RPC轻量远程调用协议，MCP 的消息格式（2.0 版本）。
服务器发送事件SSEServer-Sent Events，基于 HTTP 的单向流式推送，用于 LLM 流式输出。
OAuth 2.0OAuth 2.0行业标准授权框架，Agent 访问第三方资源的事实标准。
mTLSMutual TLS双向证书认证，服务间通信的高强度身份校验。
编排Orchestration多 Agent / 多工具的调度协调，含集中式编排与去中心化协商。
对齐Alignment让 Agent 的决策符合人类价值观，规则 / 偏好 / 文化三层落地。
数据飞轮Data Flywheel用户反馈 → bad case 沉淀 → 模型 / prompt / 工具迭代 → 效果更好的闭环。
