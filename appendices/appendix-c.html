术语表

Agent 领域核心术语中英对照

中文英文释义
智能体Agent能感知环境、自主决策、执行行动、反思结果的 AI 系统。
大语言模型LLM基于 Transformer 的大规模预训练语言模型，如 GPT-4o、Claude 3。
思维链CoTChain-of-Thought，让模型逐步推理而非一步给出答案的 prompting 技术。
思维树ToTTree-of-Thoughts，把推理过程组织成树结构，支持回溯和剪枝。
检索增强生成RAGRetrieval-Augmented Generation，先检索外部知识再生成答案。
模型上下文协议MCPModel Context Protocol，Anthropic 提出的模型-工具-数据统一连接协议。
Agent 间协议A2AAgent-to-Agent，Google 提出的 Agent 之间通信与发现协议。
工具使用Tool UseAgent 调用外部函数、API、数据库等能力完成任务的机制。
函数调用Function CallingLLM 原生支持的结构化工具调用能力，输出 JSON 格式的 tool_call。
嵌入Embedding把文本、图片转为高维向量，用于相似度搜索和记忆存储。
分词TokenLLM 处理文本的基本单位，中文通常 1–2 字一个 token。
提示词注入Prompt Injection攻击者通过用户输入篡改系统提示词，让 AI 忽略安全规则。
幻觉HallucinationLLM 生成看似合理但事实错误的内容。
可观测性Observability通过 Tracing、Logging、Metrics 理解系统内部状态的能力。
追踪Tracing记录一次请求的完整调用链（LLM、工具、数据库）。
红队测试Red Teaming模拟攻击者测试系统安全边界。
沙箱Sandbox隔离环境，用于安全执行不可信代码。
向量数据库Vector DB专门存储和检索 Embedding 的数据库，如 Pinecone、Weaviate。
提示词工程Prompt Engineering设计和优化输入提示词以提升模型输出质量的技术。
多智能体Multi-Agent多个 Agent 分工协作完成复杂任务的系统。
