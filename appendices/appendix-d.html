参考文献与延伸阅读

论文 / 博客 / 开源项目 / 课程 / 社区 / 学习路径

Agent 领域半年一次洗牌，一手信源比二手解读可靠。本清单只收两类：定义了领域方向的论文，与工程上反复被验证的工作。按「先建立判断力，再动手，最后跟进行业」的顺序阅读。

经典论文

  • Wei et al., Chain-of-Thought Prompting Elicits Reasoning in Large Language Models (2022) — CoT 开山之作，第 5 章的理论源头。
  • Yao et al., Tree of Thoughts: Deliberate Problem Solving with Large Language Models (2023) — ToT 框架。
  • Yao et al., ReAct: Synergizing Reasoning and Acting in Language Models (2023) — Agent 循环的奠基论文，第 1 章。
  • Shinn et al., Reflexion: Language Agents with Verbal Reinforcement Learning (2023) — 反思机制的来源，第 12 章。
  • Nakajima, BabyAGI (2023) — 任务驱动自主 Agent 的早期实践。
  • Park et al., Generative Agents: Interactive Simulacra of Human Behavior (2023) — 记忆架构与「小镇实验」。
  • Wang et al., LLM Powered Autonomous Agents (2023) — Agent 架构综述（Lilian Weng 博客的配套论文列表）。
  • Liu et al., AgentBench: Evaluating LLMs as Agents (2023) — Agent 评测基准，第 9 章。

必读博客

  • Lilian Weng, LLM Powered Autonomous Agents (lilianweng.github.io) — 架构设计必读，全领域引用最高的单篇。
  • Simon Willison, Prompt Injection 系列 (simonwillison.net) — 安全视角的事实标准博客。
  • Anthropic 官方博客, MCP 系列与 Building Effective Agents — 协议设计思路 + 极简 Agent 工程观。
  • OpenAI 官方文档, Function Calling 与 Agents 指南 — 工具调用的工程范式。
  • Google DeepMind, A2A 协议白皮书 — 互操作方向。

开源项目

  • LangChain — python.langchain.com — 通用 LLM 应用框架，生态最全。
  • LangGraph — github.com/langchain-ai/langgraph — LangChain 的图式编排子项目，生产推荐。
  • CrewAI — crewai.com — 多 Agent 编排，上手最快。
  • AutoGen — github.com/microsoft/autogen — 多 Agent 对话框架。
  • LlamaIndex — llamaindex.ai — RAG 与数据索引首选。
  • Dify — dify.ai — 低代码 LLM 应用平台，支持私有化。
  • OpenTelemetry — opentelemetry.io — 可观测性标准，第 10 章的落地基础。
  • MCP 官方 SDK 与示例 Server — github.com/modelcontextprotocol — 协议参考实现。
  • vLLM / SGLang — 开源模型高吞吐推理引擎，私有化部署用。

课程与视频

  • Stanford CS224N (NLP with Deep Learning) — 理解 Transformer 与 LLM 基础。
  • Andrej Karpathy, Build a Large Language Model from Scratch — 动手理解模型内部。
  • DeepLearning.AI, Building Systems with the ChatGPT API — 工程实践入门。
  • DeepLearning.AI, Multi AI Agent Systems with CrewAI — 多 Agent 编排实操。
  • Hugging Face, Agents Course — 免费的系统化 Agent 课程，带代码作业。

社区与资讯

  • Hugging Face — huggingface.co — 模型托管、论文、demo。
  • Papers With Code — paperswithcode.com — 论文 + 代码实现。
  • r/LocalLLaMA — reddit.com/r/LocalLLaMA — 开源模型与部署讨论。
  • Latent Space（播客 / 通讯）— 工程团队视角的行业深度报道。
  • MCP 官方 Discord / GitHub Discussions — 协议演进的第一现场。

研究路径跟踪前沿与做技术储备的团队论文清单按年份倒序 → OpenTelemetry / MCP 源码 → 跟进 A2A 演进持续

学习路径的分级读法：入门者（<3 个月）按「本书第 1–5 章 + 速成指南的低代码部分」建立体感；进阶者（3–12 个月）按「本书第 6–14 章 + 实战手册的框架章节」逐个框架跑 demo；生产级（1 年以上）直接研究本附录的实战项目源码（电商问数/深度研搜），对照本书第 15–18 章的工程要点逐条验证。三个级别都别跳过一个动作：自己写一个最小 Agent——看十篇不如写一个。
