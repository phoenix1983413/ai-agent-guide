参考文献与延伸阅读

论文 / 博客 / 开源项目 / 课程推荐

经典论文

  • Wei et al., Chain-of-Thought Prompting Elicits Reasoning in Large Language Models (2022) — CoT 开山之作。
  • Yao et al., Tree of Thoughts: Deliberate Problem Solving with Large Language Models (2023) — ToT 框架。
  • Nakajima, BabyAGI (2023) — 任务驱动自主 Agent 的早期实践。
  • Kim et al., LLM Powered Autonomous Agents (2023) — Agent 架构综述。

必读博客

  • Lilian Weng, LLM Powered Autonomous Agents (lilianweng.github.io) — 架构设计必读。
  • Simon Willison, Prompt Injection 系列 (simonwillison.net) — 安全视角。
  • Anthropic 官方博客, MCP 系列 — 协议设计思路。
  • Google DeepMind, A2A 协议白皮书 — 互操作方向。

开源项目

  • LangChain — python.langchain.com — 通用 LLM 应用框架。
  • CrewAI — crewai.com — 多 Agent 编排。
  • AutoGen — github.com/microsoft/autogen — 多 Agent 对话。
  • LlamaIndex — llama_index — RAG 与数据索引。
  • OpenTelemetry — opentelemetry.io — 可观测性标准。
  • MCP SDK — github.com/modelcontextprotocol — 协议参考实现。

课程与视频

  • Stanford CS224N (NLP with Deep Learning) — 理解 Transformer 和 LLM 基础。
  • Andrej Karpathy, Build a Large Language Model from Scratch — 动手理解模型内部。
  • DeepLearning.AI, Building Systems with the ChatGPT API — 工程实践入门。

社区与资讯

  • Hugging Face — 模型托管、论文、demo。
  • Papers With Code — 论文 + 代码实现。
  • r/LocalLLaMA — 开源模型与部署讨论。
  • Agent 周刊 — 每周汇总行业动态。
