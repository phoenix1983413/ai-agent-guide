第 20 章

Agent 伦理与对齐

价值对齐 / 透明性 / 责任归属 / 监管趋势

20.1 价值对齐：什么是「正确的事」

Agent 的决策必须与人类价值观对齐。挑战在于：价值观是多元的、语境依赖的、会随时间演化。工程实践中，对齐通过三层实现：

  • 规则层：硬编码红线（如「不生成暴力内容」）。
  • 偏好层：用户个人偏好（如「我喜欢简洁的回答」）。
  • 文化层：地域、行业、组织的文化规范（如金融行业对合规的重视程度）。

20.2 透明性：用户是否有知情权

用户必须知道自己在和 AI 交互，以及 AI 的能力边界。透明性要求：

  • 身份披露：明确告知用户对方是 AI，不是人类。
  • 能力边界：说明 Agent 能做什么、不能做什么、可能出错的地方。
  • 数据使用：告知用户哪些数据被记录、用于什么目的、保留多久。

20.3 责任归属：Agent 做错了，谁负责

法律界和产业界仍在探索，但工程上可以提前布局：

  • 可审计：所有决策链路留痕，可回溯到具体 prompt、模型版本、工具调用。
  • 可干预：人工可以随时介入、修正、撤销 Agent 的行为。
  • 可隔离：单个 Agent 故障不影响主系统，责任范围可界定。

20.4 监管趋势：EU AI Act、中国算法推荐管理规定

全球 AI 监管正在收紧，Agent 作为自主系统是重点监管对象：

  • EU AI Act：按风险分级，高风险 AI 系统（包括自主 Agent）需通过合规评估、建立风险管理体系、保持日志。
  • 中国算法推荐管理规定：算法备案、用户知情权、关闭个性化推荐选项、不得诱导用户沉迷。
  • 行业自律：ISO / IEEE 正在制定 Agent 安全标准，企业应提前跟踪。

本章产出

  • Agent 对齐的三层模型（规则 / 偏好 / 文化）。
  • 透明性 checklist：身份披露、能力边界、数据使用告知。
  • 责任归属的工程实践（可审计 / 可干预 / 可隔离）。
  • EU AI Act 和中国算法推荐管理规定的合规要点速查。
