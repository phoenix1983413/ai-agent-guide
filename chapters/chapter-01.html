第 1 章

什么是 AI Agent

定义、与 Chatbot 的区别、自主性权衡、分层能力模型

学习目标

  • 说清 Agent 与 Chatbot、Copilot、Workflow 的本质区别
  • 建立「大脑 + 眼睛 + 手脚」的心智模型与 Model–Harness 内部结构
  • 能用观察空间 / 动作空间的视角，判断一个任务卡在哪一层

章节地图：1.1 定义 → 1.2 与近亲形态对比 → 1.3 自主性权衡 → 1.4 分层能力 → 1.5 认知层级 → 1.6 观察与动作空间 → 1.7 Model–Harness → 本章产出。

1.1 Agent 的定义：感知 → 决策 → 行动 → 反思的闭环

一个 AI Agent 至少包含四个环节：

  • 感知（Perceive）：从环境获取输入——用户消息、系统状态、工具返回值。
  • 决策（Decide）：基于感知到的信息，用大模型或规则引擎决定下一步做什么。
  • 行动（Act）：调用工具、写入数据库、发送消息、修改文件。
  • 反思（Reflect）：观察行动结果，判断是否达到目标，决定继续还是调整策略。

这四个环节循环执行，直到任务完成或人工介入。这个闭环是 Agent 与 Chatbot 的根本区别。

1.2 Agent 与 Chatbot、Copilot、Workflow 的区别

类型 自主性 记忆 工具调用 典型场景
Chatbot 低——只响应当前输入 短窗口上下文 无或极少 问答、客服
Copilot 低——人类主导节奏 项目级上下文 有（补全、搜索） 代码补全、写作辅助
Workflow 中——按预定步骤执行 任务级状态 有（固定编排） 审批流、数据管道
Agent 高——自主规划与调整 多级记忆 动态注册、自主选择 复杂研究、多系统操作

1.3 自主性 vs 可控性的核心权衡

Agent 越自主，效率越高，风险也越大。关键设计决策：

  • 人工接管点：哪些步骤必须人工确认？写入数据库、发送邮件、修改配置通常需要。
  • 权限边界：Agent 能访问哪些系统、执行哪些操作？最小权限原则。
  • 回滚能力：Agent 做错了，能否快速恢复到之前状态？
  • 可观测性：Agent 的每一步决策和行动是否可审计、可复现？

1.4 分层能力模型

不是所有 Agent 都需要 L3 能力。按需选择：

  • L1 工具调用：能调用预定义工具，按顺序执行。最基础，也最可靠。
  • L2 规划：能分解任务、制定多步计划、在失败时重规划。适合复杂但结构化的任务。
  • L3 多智能体协作：多个 Agent 分工协作、共享记忆、协商决策。适合超复杂场景，也是成本最高的。

1.5 认知层级：从反射动作到通用智能

1.4 节的功能分层回答「Agent 会做什么」；认知层级回答「Agent 能自己做多少主」。两级视角配合使用：功能分层选技术栈，认知层级定自主度边界。

层级决策来源典型系统失效模式
L1 反射式输入直接映射动作，无状态规则引擎、正则、热键脚本遇到未覆盖输入即失效
L2 目标驱动人预定义流程，系统按条件执行Workflow、状态机、DAG 编排流程外场景无法处理
L3 规划执行模型自行拆解目标、调用工具、调整计划ReAct、Plan-and-Execute计划漂移、工具误用
L4 反思修正模型评估自身输出并迭代Reflexion、Self-Refine反思死循环、虚假信心
L5 群体协作多角色分工、动态组队、冲突仲裁Multi-Agent 编排协调成本吞掉收益

工程结论：自主度每升一级，不确定性和调试成本同步上升。给 Agent 的自主度应该「贴着任务需求的最低值」——这正是 1.3 节「自主性 vs 可控性」的量化落地方式。

1.6 观察空间与动作空间：接口决定能力上限

这是理解 Agent 工程最重要的视角之一：在底层模型固定时，提升任务表现最主要的系统工程手段，就是重新定义或扩展观察空间与动作空间。很多看起来「需要更聪明模型」的问题，其实是接口问题——任务所需的数据没有进入上下文，或完成任务所需的操作没有封装成工具。

  • 观察空间（上下文）：环境返回的观察、历史、记忆、检索结果。没有进入上下文的信息，对模型相当于不存在。
  • 动作空间（工具）：模型可调用的操作集合。没被动作接口允许的操作，模型即使「知道怎么做」也只能停留在文字建议上。
产品路线扩展的观察空间扩展的动作空间
Deep Research（深度调研）搜索结果、网页正文、引用来源多轮检索、笔记记录
Coding Agent代码库、报错、终端输出文件读写、命令执行、测试运行
Computer Use屏幕截图、DOM 快照鼠标、键盘、浏览器控制
通用 Agent（如 Manus）以上三者的并集 + 文件系统以上三者的并集 + 代码执行

通用 Agent 的突破并不来自「换了一个更强的模型」，而是取了三条路线的观察/动作空间并集——这是接口扩展驱动能力跃迁的最好证明。

1.7 Model–Harness：Agent 的内部解剖

把 Agent 打开，里面是两层结构：Model 负责策略决策（想做什么）；Harness 是环绕模型的运行与治理层，负责让决策真正落地。

Harness 职责具体工作对应章节
构造上下文把观察、记忆、检索结果组织成模型输入第 3 章
暴露工具接口工具注册、Schema 生成、调用分发、结果回填第 4 章
维护循环与状态ReAct 循环、计划状态、中断恢复、超时控制第 2、5 章
安全与纠正权限校验、动作验证、失败重试、人工接管第 10、11 章

工程公式可以按此展开：Agent = Model + Harness；最小 Harness = 上下文 + 工具；生产级 Harness 再加约束、验证与纠正。换模型只换了「大脑」，Harness 决定了「大脑」能看到什么、能做什么、做错了谁兜底——这是本书后续所有章节的统一坐标系。

动手实验

  1. 打开你常用的一款 Agent 产品（如 Cursor、Deep Research、Manus），列出它向你暴露的「观察通道」（你能看到它读了什么）和「动作范围」（它能替你操作什么）。
  2. 找一件你工作中重复三次以上的任务，按 1.6 节判断：它缺的是观察（信息没给够）还是动作（操作没封装）？
  3. 用一句话向同事解释 Model 与 Harness 的区别。说不清楚就回到 1.7 节的表。

Agent 五组件速记

工程上把一个 Agent 拆开，永远是这五块。记住这个类比，面试和评审都用得上：

组件作用类比常见实现
LLM（大脑）理解、推理、生成人的大脑GPT / Claude / Qwen / DeepSeek，可本地可云端
角色（Persona）划定专业领域与行为边界职业身份System Prompt
工具集（Tools）调用外部能力双手和工具函数调用 / MCP / 代码执行
记忆（Memory）短期对话历史 + 长期知识记忆系统上下文窗口 / 向量库 / Redis
决策逻辑决定下一步做什么决策中枢ReAct / ToT 循环、规划器

检查任何一个「Agent 项目靠不靠谱」，用这五条过一遍就够了：模型选型有没有理由（大脑）？系统提示词写没写清角色和禁区（角色）？工具是不是原子且带错误返回（工具）？上下文会不会无限膨胀（记忆）？有没有兜底——Agent 卡死时谁接管（决策逻辑）？五条里缺任何一条，项目后期都会以线上事故的形式补回来。

本章产出：最小 ReAct Agent（100 行）

以下是一个最简 Agent，用 ReAct（Reason + Act）循环实现。它能在「思考」和「行动」之间交替，直到找到答案。

Python 版本

"""
最小 ReAct Agent —— 100 行 Python
依赖：openai >= 1.0（或任何兼容 OpenAI 格式的 SDK）
"""
import json, re, os
from openai import OpenAI

client = OpenAI()  # 设 OPENAI_API_KEY 环境变量

TOOLS = [
    {"name": "search", "description": "搜索互联网",
     "parameters": {"type": "object", "properties": {"q": {"type": "string"}}, "required": ["q"]}},
    {"name": "calc", "description": "执行四则运算",
     "parameters": {"type": "object", "properties": {"expr": {"type": "string"}}, "required": ["expr"]}},
]

def call_tool(name: str, args: dict) -> str:
    if name == "search":
        return f"[模拟搜索结果] 关于 {args['q']} 的前三条摘要……"
    if name == "calc":
        return str(eval(args["expr"], {"__builtins__": {}}, {}))
    return f"未知工具: {name}"

def run_agent(question: str, max_rounds: int = 5):
    messages = [
        {"role": "system", "content": "你是一个 helpful agent。遇到问题先思考，需要工具就调用，直到解决问题。"},
        {"role": "user", "content": question},
    ]
    for _ in range(max_rounds):
        resp = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=messages,
            tools=[{"type": "function", "function": t} for t in TOOLS],
            tool_choice="auto",
        )
        msg = resp.choices[0].message
        messages.append(msg)
        tool_calls = msg.tool_calls
        if not tool_calls:
            return msg.content  # Agent 认为任务完成
        for tc in tool_calls:
            args = json.loads(tc.function.arguments)
            result = call_tool(tc.function.name, args)
            messages.append({"role": "tool", "tool_call_id": tc.id, "content": result})
    return "达到最大轮数，任务未完成。"

if __name__ == "__main__":
    print(run_agent("北京今天的温度是多少？"))

TypeScript 版本

/**
 * 最小 ReAct Agent —— 100 行 TypeScript
 * 依赖：openai >= 4.0（npm i openai）
 */
import OpenAI from "openai";

const client = new OpenAI(); // 设 OPENAI_API_KEY 环境变量

const TOOLS = [
  { name: "search", description: "搜索互联网",
    parameters: { type: "object", properties: { q: { type: "string" } }, required: ["q"] } },
  { name: "calc", description: "执行四则运算",
    parameters: { type: "object", properties: { expr: { type: "string" } }, required: ["expr"] } },
];

function callTool(name: string, args: Record): string {
  if (name === "search") return `[模拟搜索结果] 关于 ${args.q} 的前三条摘要……`;
  if (name === "calc") return String(eval(args.expr as string));
  return `未知工具: ${name}`;
}

async function runAgent(question: string, maxRounds = 5): Promise {
  const messages: OpenAI.ChatCompletionMessageParam[] = [
    { role: "system", content: "你是一个 helpful agent。遇到问题先思考，需要工具就调用，直到解决问题。" },
    { role: "user", content: question },
  ];

  for (let i = 0; i < maxRounds; i++) {
    const resp = await client.chat.completions.create({
      model: "gpt-4o-mini",
      messages,
      tools: TOOLS.map(t => ({ type: "function" as const, function: t })),
      tool_choice: "auto",
    });
    const msg = resp.choices[0].message;
    messages.push(msg);
    const toolCalls = msg.tool_calls;
    if (!toolCalls) return msg.content ?? "（无输出）";

    for (const tc of toolCalls) {
      const args = JSON.parse(tc.function.arguments);
      const result = callTool(tc.function.name, args);
      messages.push({ role: "tool", tool_call_id: tc.id, content: result });
    }
  }
  return "达到最大轮数，任务未完成。";
}

// 运行示例
runAgent("北京今天的温度是多少？").then(console.log);
