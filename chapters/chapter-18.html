第 18 章

场景四：个人助理 Agent

日程管理 / 邮件分类 / 信息摘要 / 主动 vs 被动触发

18.1 需求：日程管理、邮件分类、信息摘要

个人助理 Agent 是 C 端最贴近用户的形态。核心能力：

  • 日程管理：自然语言创建会议、检测冲突、建议最佳时间。
  • 邮件分类：自动归档、标记垃圾邮件、提取待办事项。
  • 信息摘要：把长文章、长邮件压缩成 bullet points，支持「详细版 / 精简版」切换。
  • 提醒：基于位置、时间、事件的主动提醒（如「你还有 30 分钟到下一个会议」）。

18.2 工具：日历、邮件、IM、提醒

个人助理的工具栈高度依赖平台 API：

  • 日历：Google Calendar / Outlook / 苹果日历。创建 / 查询 / 冲突检测。
  • 邮件：Gmail / Outlook API。分类、标记、发送。
  • IM：微信 / Slack / Telegram。被动接收 + 主动推送。
  • 提醒：系统级通知 + 应用内 badge + 邮件兜底。

18.3 记忆：用户习惯、优先级、隐私保护

个人助理记忆的粒度比其他场景更细：

  • 习惯学习：用户通常 9 点到公司、周五下午不排会、讨厌早上 8 点前的会议邀请。
  • 优先级：老板的邮件 > 客户的邮件 > 营销邮件。
  • 隐私保护：个人助理掌握大量敏感信息（健康、财务、位置），必须端侧优先、加密存储、最小化上传。

18.4 设计：主动 vs 被动触发的平衡

个人助理最容易犯的错误是「太主动」——未经允许发消息、推通知、改日程。平衡原则：

  • 默认被动：用户问什么答什么，不多嘴。
  • 低摩擦确认：主动建议时用「一键确认」，不要要求用户重新输入。
  • 免打扰：夜间、会议中、驾驶模式自动静默，只保留紧急通知。
  • 可解释性：每次主动行动都要说明理由（「因为你明天早上有个重要会议，我帮你推迟了今天的提醒」）。

"""
最小个人助理 Agent —— Python
"""
from __future__ import annotations
from dataclasses import dataclass, field
from typing import Any
import re

@dataclass
class UserProfile:
    name: str
    habits: dict[str, Any] = field(default_factory=dict)
    priorities: dict[str, int] = field(default_factory=dict)

class PersonalAssistant:
    def __init__(self, profile: UserProfile):
        self.profile = profile
        self.events: list[dict] = []
        self.emails: list[dict] = []

    def add_event(self, title: str, when: str):
        self.events.append({"title": title, "when": when, "alarm": True})
        return f"已添加：{title} @ {when}"

    def classify_email(self, subject: str, body: str) -> str:
        if "发票" in subject or "报销" in subject: return "finance"
        if "会议" in subject or "邀请" in subject: return "calendar"
        if "促销" in subject or "折扣" in subject: return "promotion"
        return "inbox"

    def summarize(self, text: str, style: str = "short") -> str:
        sentences = text.split("。")
        if style == "short": return "。".join(sentences[:2]) + "。"
        return text[:200] + "…"

    def should_notify(self, event: dict) -> bool:
        hour = int(event["when"].split(":")[0]) if ":" in event["when"] else 9
        return 9 <= hour <= 22  # 9–22 点通知，其余免打扰

# 使用示例
if __name__ == "__main__":
    assistant = PersonalAssistant(UserProfile(name="张三", habits={"work_start": "09:00"}))
    print(assistant.add_event("产品评审会", "2024-10-10 14:00"))
    print("邮件分类:", assistant.classify_email("发票报销通知", "请提交发票"))
    print("摘要:", assistant.summarize("今天是美好的一天。我们讨论了产品路线图。会议非常成功。大家一致同意下季度重点推进 Agent 场景落地。", "short"))

最小个人助理 Agent —— TypeScript
*/
interface UserProfile { name: string; habits: Record; priorities: Record; }

class PersonalAssistant {
  private profile: UserProfile;
  private events: Array> = [];
  private emails: Array> = [];

  constructor(profile: UserProfile) { this.profile = profile; }

  addEvent(title: string, when: string): string {
    this.events.push({ title, when, alarm: true });
    return `已添加：${title} @ ${when}`;
  }

  classifyEmail(subject: string, _body: string): string {
    if (subject.includes("发票") || subject.includes("报销")) return "finance";
    if (subject.includes("会议") || subject.includes("邀请")) return "calendar";
    if (subject.includes("促销") || subject.includes("折扣")) return "promotion";
    return "inbox";
  }

  summarize(text: string, style = "short"): string {
    const sentences = text.split("。").filter(Boolean);
    if (style === "short") return sentences.slice(0, 2).join("。") + "。";
    return text.slice(0, 200) + "…";
  }

  shouldNotify(event: Record): boolean {
    const hour = parseInt(event.when.split(":")[0] ?? "9");
    return hour >= 9 && hour <= 22;
  }
}
