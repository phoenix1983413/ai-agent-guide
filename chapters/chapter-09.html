第 9 章

Agent 评测与红线

功能 / 质量 / 成本评测 / 红队测试 / 持续监控

学习目标

  • 建立功能 / 质量 / 成本三维评测体系，定义各维红线
  • 看懂主流 Agent 基准测试的口径与适用范围
  • 设计线上守护指标，让「变差」在伤害用户前被发现

章节地图：9.1 功能评测 → 9.2 质量评测 → 9.3 成本评测 → 9.4 红队 → 9.5 持续监控 → 9.6 主流基准 → 9.7 线上守护 → 本章产出。

9.1 功能评测：任务完成率、步骤数、耗时

功能评测回答「Agent 能不能完成用户交给它的任务」。核心指标：

  • 任务完成率（Success Rate）：成功完成的 case 数 / 总 case 数。生产系统要求 > 95%。
  • 平均步数：完成一个任务平均需要多少次工具调用 / 思考。步数过多说明规划能力弱或走了弯路。
  • 端到端耗时：从用户发消息到最终答案返回的时间。P95 是比均值更有意义的指标。

9.2 质量评测：答案准确率、安全性、幻觉率

功能完成不代表质量过关。质量评测关注：

  • 答案准确率：与专家标注对比，分事实性错误和推理错误两类。
  • 幻觉率：Agent 输出的事实在参考文档中找不到的比例。幻觉 > 5% 通常不可接受。
  • 安全性：是否泄露敏感信息、是否执行了越权操作、是否产生有害内容。

9.3 成本评测：Token 消耗、延迟分布

Agent 的成本远高于传统软件，因为每次任务都要调用 LLM。必须监控：

  • 单任务平均 Token：输入 + 输出的总和。超过预算时考虑 prompt 压缩或模型路由。
  • 延迟分布：P50 / P95 / P99。P99 尾巴长说明存在极端慢 case，需要排查。
  • 模型路由效果：大模型做决策、小模型做执行的 cost saving 比例。

9.4 红队测试：对抗性输入、边界条件

红队测试（Red Teaming）是主动攻击自己的系统，找出安全漏洞。Agent 的红队重点：

  • 提示词注入：尝试让 Agent 忽略安全规则、输出内部提示词、执行危险操作。
  • 边界输入：超长输入、空输入、乱码、多语言混合、特殊字符。
  • 多轮对抗：单轮攻不破，尝试多轮逐步诱导 Agent 偏离。
  • 工具滥用：让 Agent 调用不相关的工具、重复调用、传入恶意参数。

9.5 持续监控：线上日志的异常检测

评测不是一次性动作，而是持续过程。上线后要监控：

  • 错误率突增：某类工具调用失败率突然升高，可能是上游服务故障或 prompt 变更导致。
  • 幻觉模式：通过日志抽样，发现高频出现的幻觉类型，反哺 prompt 修复。
  • 成本异常：单任务 token 消耗突然翻倍，说明可能进入了死循环或重复调用。

9.6 主流基准测试：AgentBench 与它的邻居们

公开基准用于「选型参考」，自建评测集才是「上线依据」。看懂基准的口径，能避免被营销数字误导：

基准测什么指标口径注意点
AgentBench通用 Agent 综合能力（OS/数据库/知识卡片等 8 类环境）任务完成率， overall score环境是沙箱，与真实工作流有差距
SWE-bench真实 GitHub issue 修复测试通过率（resolved）Coding Agent 的行业标尺；选子集对照
WebArena / Mind2Web浏览器任务操作步骤级 / 任务级成功率WebArena 可复现，Mind2Web 更接近真实网站
GAIA需要多步工具使用的通用助理问题准确率，按难度分级对人类简单对模型难，适合测「助理」形态
τ-bench（tau-bench）工具-用户-领域策略三方交互pass^k（k 次全对的概率）关注稳定性而非单次运气

使用姿势：用基准做粗筛（选模型/框架），用自建集做精判（能否上线）。自建集从哪来？上线后把「用户不满意的 case」和「人工修正的 case」持续沉淀——这是唯一带你的业务基因的评测集。

9.7 线上守护指标：让变差在伤害用户前暴露

离线评测通过不等于线上健康。上线后按天盯这五类指标，任一类连续两天越界即触发回滚评估：

指标健康信号越界动作
任务完成率波动在基线 ±5% 内回滚到上一版本提示词 / 模型
人工接管率平稳或下降接管率突增 = 某类任务开始系统性失败
平均步数 / 轮次平稳步数上涨常是「在原地打转」的前兆
单任务成本在预算带内超支先限流，再优化 prompt
用户修正率用户改Agent 结果的比例最直接的「不好用」信号

与 9.5 节的分工：9.5 是「发现异常」，本节是「定义什么叫异常」。两条都要有自动告警，且告警要能定位到提示词版本和模型版本——没有版本对齐的告警等于没告警。

动手实验

  1. 对照 9.6 节表格，选出与你场景最接近的两个基准，跑一遍你现在的模型，记录与官方数字的差距及原因。
  2. 把你的「不满意 case」整理成 20 条评测集，定义三条：输入、期望行为、评分方式。
  3. 给 9.7 节五个指标各设一个你系统的基线值和告警阈值，写成配置。

本章产出：开箱即用的 Agent 评测框架（双语言）

以下框架提供 EvalCase 数据结构、批量运行器、指标聚合器。接入真实 LLM 和工具即可跑。

Python 版本

"""
Agent 评测框架 —— Python
"""
from __future__ import annotations
import time, json
from dataclasses import dataclass, field
from typing import Any, Callable, Awaitable

@dataclass
class EvalCase:
    id: str
    input: str
    expected: str | None = None
    tags: list[str] = field(default_factory=list)
    threshold: float = 0.0

@dataclass
class EvalResult:
    case_id: str
    passed: bool
    score: float
    latency_ms: float
    tokens_used: int = 0
    error: str | None = None
    details: dict = field(default_factory=dict)

class AgentEvaluator:
    def __init__(self, agent_fn: Callable[[str], Awaitable[dict]]):
        self.agent_fn = agent_fn
        self.results: list[EvalResult] = []

    async def run_case(self, case: EvalCase) -> EvalResult:
        start = time.time()
        try:
            output = await self.agent_fn(case.input)
            latency = (time.time() - start) * 1000
            score = self._score(case, output)
            passed = score >= case.threshold
            return EvalResult(
                case_id=case.id, passed=passed, score=score,
                latency_ms=latency, tokens_used=output.get("tokens", 0),
                details=output,
            )
        except Exception as e:
            return EvalResult(case_id=case.id, passed=False, score=0,
                              latency_ms=(time.time() - start) * 1000, error=str(e))

    def _score(self, case: EvalCase, output: dict) -> float:
        if case.expected is None:
            return 1.0 if output.get("text") else 0.0
        # 简单字符串匹配；生产环境可用 embedding 相似度
        return 1.0 if case.expected in output.get("text", "") else 0.0

    async def run_suite(self, cases: list[EvalCase]) -> dict:
        self.results = [await self.run_case(c) for c in cases]
        return {
            "total": len(self.results),
            "passed": sum(1 for r in self.results if r.passed),
            "avg_latency_ms": sum(r.latency_ms for r in self.results) / len(self.results),
            "avg_score": sum(r.score for r in self.results) / len(self.results),
        }

# 使用示例
async def fake_agent(input: str) -> dict:
    return {"text": f"模拟回答：{input}", "tokens": 42}

async def main():
    evaluator = AgentEvaluator(fake_agent)
    suite = [
        EvalCase(id="c1", input="你好", expected="模拟回答：你好", threshold=0.8),
        EvalCase(id="c2", input="几点了", expected="不知道", threshold=0.5),
    ]
    report = await evaluator.run_suite(suite)
    print(json.dumps(report, ensure_ascii=False, indent=2))

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())

TypeScript 版本

/**
Agent 评测框架 —— TypeScript
*/
interface EvalCase {
  id: string;
  input: string;
  expected?: string;
  tags: string[];
  threshold: number;
}

interface EvalResult {
  caseId: string;
  passed: boolean;
  score: number;
  latencyMs: number;
  tokensUsed: number;
  error?: string;
  details: Record;
}

type AgentFn = (input: string) => Promise>;

class AgentEvaluator {
  private results: EvalResult[] = [];
  constructor(private agentFn: AgentFn) {}

  private score(case: EvalCase, output: Record): number {
    if (!case.expected) return output.text ? 1 : 0;
    return case.expected in output.text ? 1 : 0;
  }

  async runCase(case: EvalCase): Promise {
    const start = Date.now();
    try {
      const output = await this.agentFn(case.input);
      const latency = Date.now() - start;
      const score = this.score(case, output);
      return { caseId: case.id, passed: score >= case.threshold, score, latencyMs: latency, tokensUsed: output.tokens ?? 0, details: output };
    } catch (e: any) {
      return { caseId: case.id, passed: false, score: 0, latencyMs: Date.now() - start, error: e.message };
    }
  }

  async runSuite(cases: EvalCase[]): Promise> {
    this.results = await Promise.all(cases.map(c => this.runCase(c)));
    const n = this.results.length;
    return {
      total: n,
      passed: this.results.filter(r => r.passed).length,
      avgLatencyMs: this.results.reduce((s, r) => s + r.latencyMs, 0) / n,
      avgScore: this.results.reduce((s, r) => s + r.score, 0) / n,
    };
  }
}

// 使用示例
async function fakeAgent(input: string): Promise> {
  return { text: `模拟回答：${input}`, tokens: 42 };
}

(async () => {
  const evaluator = new AgentEvaluator(fakeAgent);
  const suite: EvalCase[] = [
    { id: "c1", input: "你好", expected: "模拟回答：你好", tags: ["smoke"], threshold: 0.8 },
    { id: "c2", input: "几点了", expected: "不知道", tags: ["edge"], threshold: 0.5 },
  ];
  const report = await evaluator.runSuite(suite);
  console.log(JSON.stringify(report, null, 2));
})();
