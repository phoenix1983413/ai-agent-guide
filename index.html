序章

AI Agent 权威指南

从入门到生产级落地的系统化路径

这本书讲什么

大语言模型让 Agent 从概念走向可用，但距离「可靠地部署在生产环境」还有一段工程化的路。本书试图填补这块：既有理论骨架，也有可跑的代码和可复制的架构。

读者定位

  • 主力读者：中级工程师以上、正在或即将亲手造 Agent 系统的人。
  • 延伸读者：产品经理、技术负责人、决策者——读 Part 0 即可建立判断力，不需要跟代码细节。

阅读路径

快速路线（2 小时）

Part 0 → 第 1 章 → 第 4 章 → 第 6 章

建立概念 + 看到 demo

工程路线（1 周）

Part 0 → 第 1–6 章 → 第 8–10 章 → 对应代码动手

从零搭一个可用的 Agent

专家路线（1 个月）

通读全部 21 章 + 运行所有示例 + 对照自己的系统逐节 review

生产级系统设计与审计

代码约定

本书所有示例均提供 Python 和 TypeScript 双版本，你可以在每章末尾按需切换。生产环境推荐根据团队栈二选一，不必两者都上。

每章怎么读

从第 1 章起，每一章都按统一结构组织，方便通读，也方便日后当查阅手册用：

区块作用读法建议
学习目标开头 3–5 条，说明本章要达成什么先扫一眼，带着问题读正文
章节地图一张段落导航，说明知识的展开顺序建立整体印象即可，不必强记
正文小节概念 → 机制 → 工程权衡 → 踩坑主体部分；表格可当速查卡回看
动手实验不需要真实 LLM Key 就能跑的练习想动手的人按步骤做一遍
本章产出可运行的双语言（Python + TypeScript）代码工程师直接拿去改；决策者可跳过

三种阅读节奏：决策者读 Part 0 + 第 11、14、19、21 章即可建立全局判断；工程师按章节顺序通读，代码跟着敲；研究者重点读第 5、6、12 章，沿附录 D 的论文线索延伸。

参考与致谢

本书在写作中参考了两本优秀的开源书籍，向作者致谢：

  • 《智能体 AI 权威指南》（yeasy） —— 单体/群体智能、AgentOps、故障模式与反模式的系统梳理，本书第 1、5、6、9、14 章吸收了大量议题。
  • 《深入理解 AI Agent》（李博杰） —— 「Agent = LLM + 上下文 + 工具」公式、Model–Harness 结构与上下文工程四操作，本书第 1、2、3 章的核心框架来源于此。
